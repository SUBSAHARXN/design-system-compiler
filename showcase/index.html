The 4-Layer Contract Rationale

Why the compiler is divided into 4 immutable decoupled contracts.

LAYER 1

Generation Engine

Pure color physics. Takes any raw brand hex, projects it into OKLCH perceptual space, maps chroma envelopes, and computes 11-stop ramps.

  • Linearity easing exponent 1.15
  • P3 wide-gamut expansion
  • Oklab ΔE perceptual uniformity
LAYER 2

Compiler Contract & CI Gates

Enforces mathematical governance rules. Rejects builds that cause hue collisions, inadequate contrast, or OLED glare.

  • OLED 950 floor (18.6:1 glare ceiling)
  • APCA Lc minimum thresholds
  • CVD green/red collision alarms
LAYER 3

Interaction Physics

Calculates state mutations (hover, active, focus, disabled). Implements anti-mud convex yellow hue drift toward warm amber.

  • Mud-free shadow drift (H 45°-48°)
  • Fill-border distinctness policies
  • Perceptual ΔL hover scaling
LAYER 4

Semantic Taxonomy

Maps abstract ramps to 80 semantic roles and 36 UI component tokens (button, card, badge, table, dialog, tooltip).

  • Zero hardcoded hex overrides
  • Instant light/dark mode parity
  • W3C Design Token Community Group standard
